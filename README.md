# Galbiatti Contabilidade

Site institucional desenvolvido para a Galbiatti Contabilidade Consultiva, com apresentação de serviços, equipe e canais de atendimento. O projeto reúne desenvolvimento front-end, interface responsiva e publicação com domínio próprio.

**[Ver projeto online](https://galbiatticontabilidade.com.br)** · **[Perfil do desenvolvedor](https://github.com/RAUL-AUGUSTO)**

![Galbiatti Contabilidade — identidade visual do projeto](assets/og-image.jpg)

## Sobre o projeto

A interface organiza as informações do escritório em uma página com navegação por seções, catálogo de serviços, apresentação dos profissionais, depoimentos e contatos. A identidade visual utiliza azul-marinho, detalhes em dourado e tipografia com variações para títulos e textos.

## Tecnologias

**HTML5 · CSS3 · JavaScript · Firebase Hosting · GitHub Actions**

Implementação sem frameworks e sem dependências de execução, com HTML semântico, estilos responsivos e JavaScript para as interações da interface.

## Funcionalidades

- Navegação adaptada a celulares, tablets e desktops, com indicação da seção ativa.
- Carrossel de profissionais com botões, gestos, arraste e controles por teclado.
- Biografias e descrições de serviços expansíveis.
- Acesso direto aos canais de atendimento e redes sociais.
- Páginas de privacidade e de erro personalizadas.

## Destaques técnicos

- **Responsividade:** layouts adaptáveis e apresentação da equipe ajustada ao tamanho da tela.
- **Acessibilidade:** uso de elementos semânticos, atributos ARIA, controle de foco e respeito à preferência por movimento reduzido.
- **Melhoria progressiva:** conteúdo disponível no HTML e componentes expansíveis com controles nativos.
- **Otimização de imagens:** retratos em WebP e arquivos específicos para ícones e compartilhamento.
- **SEO técnico:** metadados sociais, URL canônica, dados estruturados em JSON-LD, sitemap e robots.txt.
- **Hospedagem:** HTTPS, políticas de cache e cabeçalhos de segurança configurados no Firebase Hosting.
- **Qualidade de código:** verificações automatizadas de referências locais, sintaxe JavaScript e consistência da configuração de segurança no GitHub Actions.

## Competências aplicadas

Desenvolvimento de interfaces web, organização de conteúdo institucional, estilização responsiva, interações com o DOM, navegação por teclado, SEO técnico e configuração de hospedagem estática.
